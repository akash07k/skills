# PDF Forms

Fill, validate, and extract fields from PDF tax forms without guessing values.

1. Confirm the input PDF, operation, and output path.
2. Inspect its fields and distinguish fillable forms from scanned documents.
3. Extract field names and values when requested.
4. For filling, map only user-supplied values to existing fields. Report
   missing or ambiguous values instead of inventing them.
5. Validate the saved form by reading its fields again. Report unsupported
   fields and any mismatch between requested and saved values.

Do not summarize the document or provide tax advice.
